    Validation — what the model gets wrong, measured out of sample

    The walk-forward fit uses only the older half of the traded comps and is tested on the newer half, so the error is measured on protocols the fit never saw. The odds AUC is a 5-fold cross-validation on the peer record. No number on this page is hand-tuned.
