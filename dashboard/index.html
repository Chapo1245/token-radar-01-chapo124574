How the ranking works

Implied value = 8 × TVL0.85 × growth × maturity. The model reads only the snapshot's own figures — TVL, 7-day change, years listed with no token — never a list of names. A protocol "records no token" when DefiLlama carries no token for it; that is the record, not proof it has none. Implied values are this board's own claim, never a prediction that a token will launch.
