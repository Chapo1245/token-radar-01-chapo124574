Ranked board — pre-token protocols by implied launch value

Implied value = launch × odds × share. Launch is the fitted curve's value for the token at listing; odds is the fitted chance a token ever lists; share is the category's own-token share of that value. The 90% interval is conformal, per category. Ranks in brackets are the bootstrap rank range over 50 refits. Rows marked “token recorded” carry a token id in the snapshot but no market cap — ranked on the same curve, flagged rather than presented as having no token.
